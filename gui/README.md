Open http://127.0.0.1:8864 while the viewer is running. Launch from the repository root with `python gui/app.py` after activating your Python environment.

The camera now uses the native macOS backend in ../native/camera.py. No Linux helper is launched. It displays raw 2048×2048 mono frames, downsampled to 1024×1024 in the browser, at about two updates per second. Exposure and digital gain controls are enabled during native streaming. Requested exposure is quantized to sensor timing; the camera caption reports the applied value. Saturated pixels (≥254 DN) are marked red in the preview without altering the raw analysis data. A fresh camera start takes approximately 15 seconds. The browser needs no camera permission.

Wavefront: relative optical path difference in µm, fitted to 14 Zernike modes from reference spot displacements. Factory identity and optical parameters are loaded automatically from the native sensor read or a validated local cache. Its calibrated reference grid is the default for full-resolution frames. A measured flat reference remains available as an override. The fit removes piston and optionally removes tip/tilt only when both absolute tilt components are strictly below an adjustable per-axis cutoff (default 500 µrad = 0.5 mrad). It reports X/Y/total angles, measured/displayed Zernike coefficients, and RMS/PV before/after removal, within measured pupil coverage.

Run `python gui/app.py --offline` from the repository root to analyze saved 8-bit monochrome PNG/PGM images without USB. Load a known flat reference, set it, then load the measurement and enter the mounted lenslet focal length.

The adjustable threshold is spot intensity above background in 8-bit DN, with an additional noise floor. Minimum count, saturation, unique reference assignment and solvable spatial coverage must still pass. Large displacement, low matching coverage and high fit residual produce warnings without hiding the reconstructed wavefront. Dark, stale, diagnostic or invalid frames clear the wavefront and its metrics. Synthetic defocus recovery is tested; illuminated calibrated optical measurements remain to be validated.

Test mode streams synthetic 2048×2048 camera frames at a 14 FPS target through the normal centroid and wavefront analysis. Fiber X/Y/Z and KM100 lens tip/tilt sliders use an ideal 125 mm collimator and 100 mm WFS propagation. Actual factory reference offsets are rendered into the frames and canceled by reference subtraction. The coefficient table is expanded by default. See the root README for the optical assumptions.

The live camera and analysis FPS are displayed separately, measured over recent frames. Saved images report zero streaming FPS. PV after removal, like RMS after removal, shows Not applied when removal is disabled or either component exceeds the small-tilt cutoff.
